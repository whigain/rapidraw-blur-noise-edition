# Code of Conduct

## Our pledge

We want this project to be a respectful, constructive place for users and contributors regardless of background, identity, experience level, or device setup.

## Expected behavior

- Be respectful and assume good intent.
- Discuss technical issues with evidence and reproducible steps.
- Give feedback about code, not people.
- Respect privacy: remove personal paths, images, credentials, and private metadata from reports.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, sharing credentials, or instructions to bypass software licensing or security controls are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainer. Maintainers may remove content, close discussions, or block participation when necessary to protect the project community.
